# Flower Catalog

This is a simple flower catalog website built using HTML & CSS served with deno http server on port 8000.

## Pages
- Home (/)
- Abeliophyllum Flower Page (/abeliophyllum.html)
- Ageratum Flower Page (/ageratum.html)

### Home Page
The home page provides an overview of the flower catalog and links to the individual flower pages. [Screenshot](https://drive.google.com/file/d/1YxjZvukeq15DgtWinNgyPxA2weYrcvHr/view?usp=drive_link)

### Abeliophyllum Flower Page
